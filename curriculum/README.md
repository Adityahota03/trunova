# Phase 1 — AI Prototype (Desktop Python)

## What this folder contains

| File | Purpose |
|------|---------|
| `build.py` | Reads `raw/` JSON files → generates `output/curriculum.db` (SQLite + FTS5) |
| `benchmark_models.py` | Benchmarks Gemma-2-2B vs Phi-3-Mini: RAM, load time, tok/s, answer quality |
| `test_rag.py` | Full RAG pipeline: question → FTS5 retrieval → llama.cpp → grounded answer |
| `agent.py` | Explicit agent state machine with visible state transitions |
| `requirements.txt` | Python dependencies |
| `raw/` | Curriculum JSON files per class/subject/language |
| `output/` | Generated by `build.py` (curriculum.db, curriculum.json, manifest.json) |
| `models/` | Place GGUF model files here |

## Setup

```bash
cd curriculum

# Create virtual environment
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux/Mac

# Install dependencies
pip install -r requirements.txt

# Build the curriculum database
python build.py
```

## Download LLM models

Place GGUF files in `curriculum/models/`:

```
# Gemma 2 2B (recommended first try)
https://huggingface.co/bartowski/gemma-2-2b-it-GGUF
→ download: gemma-2-2b-it-Q4_K_M.gguf  (~1.6 GB)

# Phi-3 Mini
https://huggingface.co/microsoft/Phi-3-mini-4k-instruct-gguf
→ download: Phi-3-mini-4k-instruct-q4.gguf  (~2.2 GB)
```

## Run order (Stage A → B → C)

### Stage A — Benchmark models
```bash
python benchmark_models.py
```

### Stage B — RAG pipeline (prove offline works)
```bash
# Disable Wi-Fi / airplane mode first

python test_rag.py "What is photosynthesis?"
python test_rag.py "Explain Newton's first law" --class 9 --subject science
python test_rag.py --  # interactive mode
```

### Stage C — Full agent with state machine
```bash
python agent.py "What is photosynthesis?" --class 9 --subject science
python agent.py --  # interactive mode
```

## Phase 1 Success Criteria

- [ ] `python build.py` → `output/curriculum.db` created with FTS5
- [ ] `python benchmark_models.py` → comparison table printed
- [ ] Airplane mode ON → `python test_rag.py "What is photosynthesis?"` → grounded answer
- [ ] `python agent.py` → all state transitions visible, answer returned offline

## Curriculum schema

```sql
curriculum_content (
    id              TEXT PRIMARY KEY,
    class_level     INTEGER,   -- 6, 7, 8, 9, 10, ...
    subject         TEXT,      -- 'science', 'mathematics', 'english'
    language        TEXT,      -- 'en', 'hi', 'or', 'mr'
    curriculum      TEXT,      -- 'NCERT', 'SCERT-Odisha'
    chapter         TEXT,
    topic           TEXT,
    content         TEXT,
    source_ref      TEXT,
    content_version TEXT
)
```
